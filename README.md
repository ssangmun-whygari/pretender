# pretender
영화, TV 프로그램의 댓글에 기반한 인공지능 요약을 제공하는 정보 커뮤니티 사이트입니다.

## 배포 링크
http://pretender-frontend-bucket.s3-website.ap-northeast-2.amazonaws.com/

## 기술 스택
Spring Boot, Java, Vue.js, Python, Hugging Face, MariaDB, MyBatis, Chart.js, Three.js
